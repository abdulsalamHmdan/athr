منصة نقاط الأثر
│
├── 🌐 الصفحات العامة (بدون تسجيل دخول)
│   │
│   ├── /  ........................ الصفحة الترحيبية
│   │      نبذة: واجهة دخول المنصة، تعرّف الزائر بالفكرة
│   │      وتقدّم زرّين: «تسجيل كسفير جديد» و«تسجيل الدخول».
│   │
│   ├── /signup ................... تسجيل سفير جديد
│   │      نبذة: نموذج إنشاء حساب سفير جديد بالبيانات
│   │      الأساسية (الاسم، الجوال، الجهة، كلمة المرور).
│   │
│   ├── /login .................... تسجيل دخول السفير
│   │      نبذة: دخول السفير لحسابه عبر رقم الجوال وكلمة
│   │      المرور، مع رابط لاستعادة كلمة المرور.
│   │
│   ├── /forgot-password .......... استعادة كلمة المرور
│   │      نبذة: صفحة إعادة تعيين كلمة المرور للسفير في حال
│   │      نسيانها.
│   │
│   ├── /arafah ................... حملة يوم عرفة
│   │      نبذة: صفحة تحفيزية موسمية «النقطة بنقطتين» تضاعف
│   │      نقاط السفير في يوم عرفة وتشرح آلية المضاعفة.
│   │
│   ├── /share .................... شارك أثرك
│   │      نبذة: صفحة جاهزة لمشاركة رسالة الحملة مع عبارات
│   │      الشكر للنشر عبر واتساب ووسائل التواصل.
│   │
│   ├── /mbarkh ................... بطاقة المعايدة
│   │      نبذة: صفحة معايدة مصمّمة للمناسبات لمشاركتها
│   │      من السفير لمتبرعيه ومتابعيه.
│   │
│   ├── /centers .................. قائمة المجمعات والدور
│   │      نبذة: عرض جميع مجمعات ودور التحفيظ التابعة
│   │      للجمعية مع إحصائيات إجمالية (عدد الجهات،
│   │      السفراء، الصناديق).
│   │
│   ├── /centers/:id .............. تفاصيل مجمّع/دار محددة
│   │      نبذة: صفحة كل جهة بإحصائياتها الخاصة، عدد
│   │      سفرائها، وتبرعاتها، مع رابط للوحة الشرف.
│   │
│   ├── /centers/:id/board ........ لوحة شرف المجمّع
│   │      نبذة: عرض ترتيب سفراء المجمع الواحد حسب
│   │      الأداء والنقاط بشكل تنافسي تحفيزي.
│   │
│   └── /dashboard ................ لوحة الإحصائيات المباشرة
│          نبذة: شاشة عرض حيّة (Live) للإحصائيات العامة
│          للمنصة، مناسبة للعرض على الشاشات الكبيرة.
│
│
├── 👤 صفحات السفير (تتطلب تسجيل دخول)
│   │
│   ├── /ambassador/home .......... الصفحة الرئيسية للسفير
│   │   │   نبذة: قلب لوحة السفير — يطّلع على رصيده المتاح،
│   │   │   إجمالي نقاطه، النقاط الإضافية، المصروف كمكافآت،
│   │   │   الهدف القادم، وشريط تقدّم ذكي بالمستويات.
│   │   │   تحتوي على تبويبات داخلية:
│   │   │
│   │   ├── ?tab=funds ........... صناديقي
│   │   │     نبذة: عرض جميع الصناديق التي أنشأها السفير
│   │   │     مع المؤشرات العامة (الإجمالي/المكتمل/غير
│   │   │     المكتمل) ورسالة النشر الجاهزة لكل صندوق.
│   │   │
│   │   ├── ?tab=create .......... إنشاء صندوق جديد
│   │   │     نبذة: نموذج إنشاء صندوق سهمي جديد يحدد فيه
│   │   │     السفير الاسم والهدف ويستلم رابط مشاركة جاهز.
│   │   │
│   │   └── ?tab=prizes .......... طلب جائزة (صرف النقاط)
│   │         نبذة: تحويل النقاط لجوائز حقيقية — يختار
│   │         السفير الجائزة من القائمة ويقدّم طلب صرف
│   │         يصل للإدارة للمراجعة.
│   │
│   ├── /ambassador/prizes-gallery  معرض الجوائز
│   │      نبذة: استعراض كامل لجوائز المنصة بثلاث فئات
│   │      (ذهبية، فضية، برونزية) مع إمكانية التصفية —
│   │      للاطلاع فقط، والطلب من تبويب الجوائز.
│   │
│   └── /ambassador/maintenance ... صفحة الصيانة
│          نبذة: شاشة بديلة تظهر للسفراء عند تعطّل المنصة
│          أو خلال أعمال الصيانة المجدولة.
│
│
├── 🛡️ صفحات الإدارة (تتطلب تسجيل دخول الأدمن)
│   │
│   ├── /admin/login .............. تسجيل دخول الإدارة
│   │      نبذة: بوابة دخول المسؤولين عبر رقم الجوال
│   │      وكلمة المرور للوصول للوحة الإدارة.
│   │
│   ├── /admin/dashboard .......... لوحة الإدارة الرئيسية
│   │   │   نبذة: نظرة شاملة لأداء المنصة — مجموع
│   │   │   التبرعات، الجوائز المصروفة، عدد السفراء،
│   │   │   ومنسوبي الجمعية، مع تبويبات داخلية:
│   │   │
│   │   ├── الملخص ............... المؤشرات الكلية والنشاط الأخير
│   │   ├── الرسومات ............. رسوم بيانية لأداء المنصة
│   │   └── السفراء .............. قائمة السفراء قابلة للبحث والتصدير
│   │
│   ├── /admin/requests ........... متابعة طلبات الجوائز
│   │      نبذة: مركز معالجة طلبات صرف الجوائز —
│   │      فلترة حسب الحالة (قيد المراجعة/مقبولة/تم
│   │      الصرف/مرفوضة) واتخاذ إجراءات القبول والرفض.
│   │
│   ├── /admin/bonus-points ....... النقاط الإضافية
│   │      نبذة: إضافة نقاط تحفيزية للسفراء (مكافأة،
│   │      مهمة خاصة، تحفيز...) وتُحتسب مع نقاطهم
│   │      الأساسية في الإجمالي.
│   │
│   └── /admin/notifications ...... إرسال الإشعارات
│          نبذة: إنشاء رسائل تنبيه عامة أو موجّهة لسفير
│          محدد عبر إشعارات الويب، مع سجل الإرسال.
│
│
└── 🔗 روابط ذكية خاصة
    │
    └── /r/:code .................. رابط السفير المباشر
           نبذة: رابط فريد يحمله السفير في رسائله، عند
           فتحه يسجّل الزائر دخوله تلقائياً بحساب السفير
           ويحوّله مباشرة إلى صفحته الرئيسية.

                 ملخّص بنية المنصة في سطر
════════════════════════════════════════════════════════════════
المنصة تنقسم إلى ٤ طبقات:
  ١) صفحات عامة تعريفية ومناسباتية وعرض المجمعات.
  ٢) لوحة السفير الشخصية (الصناديق + الجوائز + التقدّم).
  ٣) لوحة الإدارة (المؤشرات + الطلبات + النقاط + الإشعارات).
  ٤) روابط ذكية لتسجيل دخول تلقائي عبر كود السفير.
